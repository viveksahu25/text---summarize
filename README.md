# Text Summarizer

An AI-powered text summarization web application built using FastAPI and Hugging Face T5 Transformer.

## About the Project

This project takes a long piece of text as input and generates a shorter summary using a trained T5 Transformer model.

The application has a FastAPI backend and a simple HTML, CSS and JavaScript frontend.

## Features

- Text summarization using T5 Transformer
- FastAPI backend
- Simple and user-friendly web interface
- Hugging Face Transformers
- PyTorch
- CPU/GPU support
- REST API endpoint for summarization

## Technologies Used

- Python
- FastAPI
- Uvicorn
- PyTorch
- Hugging Face Transformers
- T5
- HTML
- CSS
- JavaScript
